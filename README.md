# Лабораторная работа: Рекурсия и стек

## Цель
Научиться писать рекурсивные функции с базовым случаем и реализовать стек.

## Файлы проекта
- `recursion.py` — рекурсивные факториал, сумма списка, бинарный поиск.
- `stack.py` — класс `Stack`.
- `demo.py` — демонстрация работы всего.

## Реализация

### 1. Факториал (рекурсивный)

```python
def factorial(n):
    if n == 0 or n == 1:
        return 1
    return n * factorial(n - 1)
```

Базовый случай — `n == 0` или `n == 1`. Без него рекурсия была бы бесконечной.

### 2. Сумма списка (рекурсивная)

```python
def sum_list(arr):
    if not arr:
        return 0
    return arr[0] + sum_list(arr[1:])
```

Базовый случай — пустой список. Возвращает 0 — нейтральный элемент для сложения.

### 3. Бинарный поиск (рекурсивный)

```python
def binary_search(arr, target, left=0, right=None):
    if right is None:
        right = len(arr) - 1
    if left > right:
        return -1
    mid = (left + right) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search(arr, target, mid + 1, right)
    else:
        return binary_search(arr, target, left, mid - 1)
```

Базовые случаи: элемент найден, либо область поиска пуста (`left > right`).
Сложность — O(log n), память — O(log n) из-за стека вызовов.

### 4. Класс Stack

Реализованы методы `push`, `pop`, `peek`, `is_empty`.
Внутри используется список Python.
`pop` и `peek` на пустом стеке вызывают `IndexError`.

## Как работает рекурсия

Каждый вызов функции кладёт в стек новый кадр. Когда доходим до базового случая,
начинаем «разворачиваться» обратно, возвращая значения.

Пример для `factorial(3)`:

```
factorial(3) → 3 * factorial(2)
                    factorial(2) → 2 * factorial(1)
                                       factorial(1) → 1   ← базовый случай
                    factorial(2) → 2 * 1 = 2
factorial(3) → 3 * 2 = 6
```

## Ограничения рекурсии

- В Python по умолчанию глубина рекурсии около 1000.
- Для больших n факториал рекурсивно считать нельзя — будет `RecursionError`.
- Для длинных списков рекурсивную сумму тоже лучше не использовать —
  встроенная функция `sum()` работает итеративно и не упирается в стек.

## Вывод

Рекурсия позволяет компактно выражать алгоритмы, сводя задачу к меньшей подзадаче.
Важно всегда определять базовый случай, иначе будет переполнение стека вызовов.
Класс `Stack` показывает LIFO-структуру данных — полезную для обхода в глубину,
вычислений в обратной польской записи и других задач.
